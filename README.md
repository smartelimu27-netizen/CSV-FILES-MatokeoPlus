
# MatokeoPlus — CSV Templates

Welcome to the **MatokeoPlus CSV Templates Repository**.

This repository provides structured CSV template files designed for use with the **MatokeoPlus School Results Management System**. The templates help schools and teachers prepare and import student information, student characteristics, and academic marks into the application.

## 📁 Repository Contents

The files are organized according to **class/standard level** and the type of information being managed.

### 1. Student Information

These templates are used to prepare basic student records, including information such as:

* Student identification number
* Student name
* Gender
* Date of birth
* Class/standard
* Parent or guardian information
* Parent/guardian contact details
* Other required student information

### 2. Student Characteristics

The student-characteristics templates are designed for recording information related to students' behaviour, discipline, participation, and other school-related characteristics.

These files may contain fields appropriate to the particular class or assessment structure.

### 3. Academic Marks

The marks templates are organized **class-wise** and are intended for entering students' academic performance.

Depending on the class, the templates may contain different subjects because the subjects offered can vary between class levels.

Examples include:

* Kiswahili
* English
* Hisabati
* Science
* Historia
* Geography/Mazingira
* Sanaa na Utamaduni
* Other subjects applicable to the respective class

## 📚 Class-Wise Organization

The repository contains templates for different classes/standards.

Each class may have its own:

* Student information template
* Student characteristics template
* Academic marks templates
* Subject-specific CSV files

This class-wise organization makes it easier to select the correct template when preparing school data for import into MatokeoPlus.

## 📝 How to Use the Templates

1. Select the appropriate **class/standard**.
2. Download the required CSV template.
3. Open the file using a spreadsheet application such as:

   * Microsoft Excel
   * LibreOffice Calc
   * Google Sheets
4. Enter the required student information or marks.
5. Do **not change the column headings** unless the MatokeoPlus documentation specifically instructs you to do so.
6. Keep the data in the same format and structure as provided in the template.
7. Save the completed file in **CSV format**.
8. Import the CSV file into MatokeoPlus using the appropriate import function.

## ⚠️ Important Data Entry Guidelines

To ensure successful import into MatokeoPlus:

* Use the correct template for the student's class.
* Do not delete required columns.
* Do not rename column headings.
* Do not add unnecessary columns.
* Enter marks using the required numerical format.
* Ensure student identification numbers are correct and consistent.
* Avoid unnecessary spaces in student names or identification numbers.
* Check the CSV file carefully before importing it into MatokeoPlus.
* Always keep a backup of your original school data.

## 🔐 Privacy and Security

The templates in this repository are intended for **data preparation and demonstration purposes**.

**Do not upload real or confidential student information to this public repository.**

In particular, do not upload:

* Real student names
* Real student identification numbers
* Parents' telephone numbers
* Parents' email addresses
* Passwords
* Login credentials
* School account credentials
* API keys
* SMS or email service credentials
* Private databases
* Other personally identifiable or confidential information

When sharing templates publicly, use **sample or placeholder data only**.

## 📊 CSV Format

The templates use the **Comma-Separated Values (CSV)** format.

CSV files are widely supported by spreadsheet applications and are suitable for transferring structured data between the templates and MatokeoPlus.

For example:

```text
student_id,student_name,kiswahili
001,STUDENT NAME,45
002,STUDENT NAME,47
```

The actual columns and subjects may differ depending on the class and template.

## 🏫 Designed for MatokeoPlus

These templates are developed to support the workflow of **MatokeoPlus**, a school results management application designed to assist schools in managing student information, academic marks, student characteristics, results processing, reporting, and related school activities.

The repository may be updated from time to time when:

* New classes are added
* New subjects are introduced
* Existing templates are improved
* CSV structures are updated
* New import features are introduced

If a template is updated, download the latest version from this repository before preparing new data.

Avoid using an old template when a newer version is available, as changes to column names or data structure may affect the import process.

## 📌 Important

These files are **templates for use with MatokeoPlus**.

# How to Download MatokeoPlus CSV Templates

Follow the steps below to download the folder containing the CSV templates for **student information, student characteristics, and academic marks**.

## Step 1: Open the MatokeoPlus Templates Repository

Open the MatokeoPlus GitHub repository provided to you or click a button in MatokeoPlus designed to link to MatokeoPlus GitHub repository.

You will see folders containing the available CSV templates.

## Step 2: Open the Required Folder

Click the folder containing the templates you need.

For example:

```text
marks
```

Inside the folder, you may find templates organized according to class or standard.

Example:

```text
marks
├── Standard_01
├── Standard_02
├── Standard_03
├── Standard_04
├── Standard_05
├── Standard_06
└── Standard_07
```

## Step 3: Download the Folder

GitHub does not normally provide a **Download Folder** button for an individual folder.

The easiest method is to download the **entire repository**.

1. Go back to the main page of the repository.
2. Click the green **Code** button.
3. Select **Download ZIP**.
4. Wait for the download to finish.

## Step 4: Extract the ZIP File

After downloading:

1. Locate the downloaded `.zip` file on your computer.
2. Right-click the file.
3. Select **Extract All**.
4. Choose where you want to save the files.
5. Click **Extract**.

You will now have a folder containing the CSV templates.

## Step 5: Select the Required Template

Open the extracted folder and navigate to the class you need.

For example:

```text
MatokeoPlus-Templates
    ↓
marks
    ↓
Standard_04
```

You can then select the required CSV file.

## Step 6: Open the CSV File

You can open the CSV file using:

* Microsoft Excel
* LibreOffice Calc
* Google Sheets
* Another CSV-compatible spreadsheet application

Enter your school data while keeping the existing **column headings and file structure unchanged**.

## ⚠️ Important

Before importing the completed CSV file into MatokeoPlus:

* Make sure you selected the correct class.
* Do not rename the column headings.
* Do not delete required columns.
* Check that the student information is correct.
* Check that the marks are entered correctly.
* Save the completed file as **CSV**.
